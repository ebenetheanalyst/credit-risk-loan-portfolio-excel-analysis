# Credit Risk & Loan Portfolio Analysis — Excel

## Overview
The objective was to analyze a loan portfolio and identify patterns associated with loan default, debt burden, credit score, repayment behavior, loan type, branch performance, and loan-officer activity.

## Business Problem
Financial institutions need to understand the factors associated with loan defaults so they can identify areas of portfolio risk and make better lending and monitoring decisions.

This project explores:
- The relationship between Debt-to-Income (DTI) and default rates
- Portfolio value at risk
- Default rates across credit-score bands
- First-payment default behavior
- Default patterns across branches
- Loan type performance
- Loan-officer default patterns

## Key Findings
- Default rates increased substantially as debt burden increased.
- Low DTI loans had a 5.48% default rate.
- Severe DTI loans had a 43.50% default rate.
- A single missed first payment was not, by itself, a strong indicator of eventual default.
- Credit score appeared to provide less differentiation among borrowers with severe debt burdens.
- Differences between loan officers should not automatically be treated as performance differences without considering statistical variation.
